# 03_translation/tables

- **الصنف:** مؤلف — شغل يدوي لا يعوض: git + نسخة احتياطية (pack).
- **المالك:** translation — الترجمة: الجداول، المسرد، ترجمة الكتسينات
- **يحتوي:** جداول الترجمة الرئيسية: مفتاح + source + target (+status...) — عربي منطقي دائما
- **ممنوع:** نسخ بأسماء final/copy/v2؛ نص مشكل مسبقا

> معيار L10N-STD 1.0 (l10n-std: 1.0) — تحقق: `python tools/l10n_ws.py check` · المالك: `python tools/l10n_ws.py owner <path> --role <role>`
